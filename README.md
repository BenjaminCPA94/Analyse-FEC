# Analyse-FEC
## Leads expert-comptable

`Leads_Expert_Comptable.html` : à ouvrir dans le navigateur, sans installation. L'outil repère les nouvelles sociétés (immatriculations) et les sociétés en changement (rachat de fonds, transfert de siège, nouveau dirigeant, changement de forme) dans le BODACC, sur les départements choisis. Il attribue un score à chaque lead, complète les fiches avec l'annuaire officiel des entreprises et exporte en CSV. Des liens Google Maps, PagesJaunes et « Chercher le site » aident à retrouver téléphone et e-mail, à saisir dans le suivi. Le suivi (statut, contacts, notes) reste dans le navigateur.
